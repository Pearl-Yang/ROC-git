# 云端部署手册（v1.2）

> 适用版本：ROC-git v1.2.0+
> 推荐云：阿里云 ECS + 阿里云 ACR + 阿里云 RDS（腾讯云同构可参考）
> 部署方式：docker compose + 私有镜像仓库

---

## 0. 整体流程

```
1. 注册域名 → ICP 备案 → 申请 SSL 证书
2. 阿里云控制台：
   ├─ 创建 ACR 个人版（命名空间 + 仓库 backend/frontend）
   ├─ 创建 RDS for MySQL 8.0（建库 roc_git）
   └─ 创建 OSS bucket（rocgit-files，公读私写）
3. 推送镜像：
   ├─ 方式 A：GitHub Actions 自动（推荐，配 4 个 Secrets）
   └─ 方式 B：本地 ./scripts/push-images.sh
4. ECS 一键编排：
   docker compose -f docker-compose.cloud.yml up -d
5. 配置 HTTPS（nginx.https.conf + Let's Encrypt）
6. 配置监控 + 备份（monitor compose + crontab）
```

## 1. 前置资源清单

| 资源 | 最低规格 | 备注 |
| --- | --- | --- |
| 阿里云 ECS | 2 vCPU / 4 GiB / 40 GiB SSD | 2 Mbps 带宽起，CentOS 8 / Ubuntu 22.04 |
| 阿里云 RDS for MySQL 8.0 | 1 vCPU / 2 GiB / 50 GiB | 必开内网访问 |
| 阿里云 ACR 个人版 | 免费版 | 命名空间 + 2 个仓库（backend / frontend） |
| 阿里云 OSS | 标准存储 50 GiB | 公读私写 + 跨区复制 |
| 备案域名 | — | 必须完成 ICP 备案 |
| SSL 证书 | DV 单域名 | Let's Encrypt 自动续期 |

## 2. 镜像仓库：阿里云 ACR

1. 控制台 → 容器镜像服务 → 个人版 → 创建命名空间 `rocgit`
2. 在命名空间下创建仓库：
   - `rocgit/backend`（本地源 / 华东1）
   - `rocgit/frontend`
3. 访问凭证 → 设置 Registry 登录密码（独立密码，不是阿里云账号密码）
4. 本地登录测试：
   ```bash
   docker login registry.cn-hangzhou.aliyuncs.com
   # 用户名：阿里云账号（不是邮箱）
   # 密码：上一步设置的 Registry 独立密码
   ```

> **腾讯云 TCR 等价做法**：控制台 → 容器镜像服务 TCR → 创建个人版实例 + 命名空间 + 仓库，登录地址 `ccr.ccs.tencentyun.com`。

## 3. 推送镜像（两种方式）

### 方式 A：GitHub Actions（推荐）

在 GitHub 仓库 → Settings → Secrets and variables → Actions 添加：

| Secret 名称 | 内容 |
| --- | --- |
| `ALIYUN_REGISTRY_USERNAME` | 阿里云账号 |
| `ALIYUN_REGISTRY_PASSWORD` | Registry 独立密码 |
| `TENCENT_REGISTRY_USERNAME` | （腾讯云可选） |
| `TENCENT_REGISTRY_PASSWORD` | （腾讯云可选） |

然后：

```bash
git tag v1.0.0
git push origin v1.0.0
# 自动触发 .github/workflows/image-publish.yml
```

或在 GitHub → Actions 标签页 → 选 `image-publish` → Run workflow，填 `tag=1.0.0` `cloud=aliyun`。

构建结果会同时推：
- `registry.cn-hangzhou.aliyuncs.com/rocgit/backend:1.0.0`
- `registry.cn-hangzhou.aliyuncs.com/rocgit/backend:latest`
- `registry.cn-hangzhou.aliyuncs.com/rocgit/frontend:1.0.0`
- `registry.cn-hangzhou.aliyuncs.com/rocgit/frontend:latest`

### 方式 B：本地手推

```bash
# 1) 登录（首次）
docker login registry.cn-hangzhou.aliyuncs.com

# 2) 推 backend + frontend
chmod +x scripts/push-images.sh
./scripts/push-images.sh -t 1.0.0

# 只推 frontend
./scripts/push-images.sh -t 1.0.0 -s frontend

# 推腾讯云
./scripts/push-images.sh -t 1.0.0 -r tencent
```

## 4. 云端 MySQL：阿里云 RDS

1. 控制台 → 云数据库 RDS → 创建 MySQL 8.0（包年包月或按量）
2. 实例创建后 → 数据库管理 → 创建数据库 `roc_git`（utf8mb4_unicode_ci）
3. 账号管理 → 创建账号 `rocgit`（读写权限，授权库 `roc_git`）
4. 数据安全 → 白名单 → 添加 ECS 内网 IP
5. 通过 ECS 内网初始化数据（任选其一）：

```bash
# 方式 1：用脚本在 ECS 上 reseed
git clone <your-repo>  # 或 scp 上 backend/database 目录
cd <repo-root>
DB_HOST=<RDS 内网地址> DB_USER=rocgit DB_PASSWORD=<pwd> \
  ./scripts/reseed.sh

# 方式 2：用 DMS 控制台直接导入
# 阿里云控制台 → 数据管理 DMS → 登录 RDS → 数据方案 → 导入
#   - 01-schema.sql
#   - 02-seed.sql
#   - 03-migration-add-phone.sql
#   - 03-update.sql
#   - 04-privacy-compliance.sql
```

> **注意**：`reseed.sh` 默认会 `DROP DATABASE`，**只用于初始化**；生产有数据后请改用迁移脚本 + 备份恢复。

## 5. 首次部署

### 5.1 准备环境变量

```bash
cd <repo-root>
cp .env.cloud.example .env.cloud
vi .env.cloud
# 必填：REGISTRY / IMAGE_NAMESPACE / IMAGE_TAG
# 必填：DB_HOST / DB_USER / DB_PASSWORD
# 必填：DOMAIN / JWT_SECRET
# 可选：TENCENT_SMS_*（生产环境建议接真实短信）
```

生成 JWT secret：
```bash
openssl rand -base64 64
```

### 5.2 准备 SSL 证书

```bash
# Let's Encrypt（自动续期）
sudo apt install certbot -y
sudo certbot certonly --standalone -d rocgit.example.com
sudo mkdir -p ./ssl
sudo cp /etc/letsencrypt/live/rocgit.example.com/fullchain.pem ./ssl/
sudo cp /etc/letsencrypt/live/rocgit.example.com/privkey.pem   ./ssl/

# 也可放自有证书到 ./ssl/cert.pem + ./ssl/key.pem
```

### 5.3 ECS 上登录镜像仓库

```bash
# 阿里云
docker login registry.cn-hangzhou.aliyuncs.com
```

### 5.4 docker compose 拉起

```bash
docker compose -f docker-compose.cloud.yml --env-file .env.cloud pull
docker compose -f docker-compose.cloud.yml --env-file .env.cloud up -d
docker compose -f docker-compose.cloud.yml logs -f backend
```

### 5.5 验证

```bash
# 后端健康
curl https://rocgit.example.com/api/v1/health
curl https://rocgit.example.com/api/v1/health/db

# 前端
open https://rocgit.example.com/

# Knife4j
open https://rocgit.example.com:8080/doc.html
```

> 默认 `docker-compose.cloud.yml` 没把 8080 暴露到公网，安全考虑；
> 通过 nginx `/api/*` 反代访问后端。如要直接暴露，编辑 `docker-compose.cloud.yml` 加上 `ports: ["8080:8080"]`。

## 6. 监控 / 备份

### 6.1 监控（Prometheus + Grafana + Alertmanager）

`docker-compose.monitor.yml` 已经在仓库内，已配置好 backend 的 `/actuator/prometheus`。
云端启动：
```bash
docker compose -f docker-compose.monitor.yml up -d
# Grafana → http://<ECS IP>:3000  (admin / admin 首次登录会要求改密码)
# Prometheus → http://<ECS IP>:9090
```

告警通道：编辑 `monitor/alertmanager.yml`，把 webhook 换成钉钉 / 飞书 / 邮件。

### 6.2 备份

`scripts/backup.sh` 默认每天凌晨 2 点全量 dump：
```bash
# 加入 crontab
crontab -e
0 2 * * * /opt/rocgit/scripts/backup.sh >> /var/log/rocgit/backup.log 2>&1
```

云端推荐同步到 OSS / COS：
- 编辑 `scripts/backup.sh`，填入 `S3_BUCKET=<OSS bucket 名>`
- 安装 `awscli` 并 `aws configure`（用阿里云 RAM 子账号 AccessKey）

## 7. 升级 / 回滚

```bash
# 1) 改 .env.cloud 的 IMAGE_TAG
sed -i 's/IMAGE_TAG=1.0.0/IMAGE_TAG=1.0.1/' .env.cloud

# 2) 拉新镜像 + 滚动重启
docker compose -f docker-compose.cloud.yml --env-file .env.cloud pull
docker compose -f docker-compose.cloud.yml --env-file .env.cloud up -d

# 3) 验证
curl https://rocgit.example.com/api/v1/health/db
```

回滚：
```bash
sed -i 's/IMAGE_TAG=1.0.1/IMAGE_TAG=1.0.0/' .env.cloud
docker compose -f docker-compose.cloud.yml --env-file .env.cloud up -d
```

## 8. 常见问题

### 8.1 域名备案

国内上线必须先 ICP 备案（阿里云 / 腾讯云都提供备案入口），通常 7-20 天。

### 8.2 微信小程序合法域名

登录 mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名：
- request 合法域名：`https://rocgit.example.com`
- uploadFile 合法域名：`https://rocgit.example.com`
- downloadFile 合法域名：`https://rocgit.example.com`

`frontend/src/manifest.json` 关闭 `mp-weixin.setting.urlCheck` 仅供开发期。

### 8.3 短信

默认 `SMS_PROVIDER=log`，验证码会写到容器内 `logs/sms-*.log`。
生产前在 `.env.cloud` 填 4 个腾讯云凭证，并改 `SMS_PROVIDER=tencent`。

### 8.4 对象存储（OSS / COS）

S3 兼容接口骨架已在 [S3FileStorageService.java](file/backend/src/main/java/com/rocgit/knife4j/service/storage/S3FileStorageService.java)。
接入后 `rocgit.file.storage=s3`，容器内挂 `awscli` 或 sidecar（待后端 service 完整切换）。

### 8.5 防火墙 / 安全组

ECS 安全组放行：
- 入：80, 443（公网）
- 入：22（SSH，限自己 IP）
- 入：3000, 9090, 9093（监控，可限公司 IP）
- 出：全部（拉镜像、连 RDS、备份到 OSS）

RDS 安全组：仅放行 ECS 内网 IP。

## 9. W2 · 对象存储 OSS / COS 切换

### 9.1 前提条件

阿里云 OSS 或腾讯云 COS bucket（公读私写，S3 兼容模式）。

### 9.2 迁移流程

```bash
# 1) 在 .env.cloud 中填入凭证
ROCGIT_FILE_PROVIDER=local   # 当前保持 local
ROCGIT_FILE_S3_ENDPOINT=https://oss-cn-shanghai.aliyuncs.com
ROCGIT_FILE_S3_BUCKET=rocgit-files
ROCGIT_FILE_S3_ACCESS_KEY=<RAM AccessKey>
ROCGIT_FILE_S3_SECRET_KEY=<RAM SecretKey>

# 2) 执行迁移（见 scripts/migrate-local-to-oss.sh）
./scripts/migrate-local-to-oss.sh

# 3) 观察 migrate 报告（SUCCESS / FAILED）
# 4) 确认全部成功后，切换
sed -i 's/ROCGIT_FILE_PROVIDER=local/ROCGIT_FILE_PROVIDER=s3/' .env.cloud
docker compose -f docker-compose.cloud.yml --env-file .env.cloud up -d

# 5) 监控 5xx，上传成功率
# 6) 7 天后确认无问题，删除 ./data/files 本地文件
```

> **注意**：迁移脚本生成的 `local-to-oss.map.csv` 保留在 `/opt/rocgit/backup/` 便于溯源。

### 9.3 OSS 上传失败排查

```bash
# 1) 检查 endpoint / bucket / credential
docker compose logs backend | grep S3FileStorage

# 2) 检查 IAM 权限（OSS 需要 oss:PutObject / oss:GetObject / oss:DeleteObject）
# 3) 检查 bucket 跨区域复制（CORS / Referer 白名单）
```

## 10. W3 · 文件锁 / 微信登录

### 10.1 文件锁

后端已接入：
- `POST /api/v1/file/{id}/lock` · 申请锁（默认 5 分钟）
- `POST /api/v1/file/{id}/unlock` · 释放锁
- `GET /api/v1/file/{id}/lock` · 查锁状态
- 定时任务每分钟自动清理过期锁

### 10.2 微信小程序登录

```bash
# .env.cloud 中填入微信小程序凭证
WECHAT_MP_APP_ID=wx...
WECHAT_MP_APP_SECRET=...

# 生产：mp.weixin.qq.com → 开发管理 → 服务器域名配置 request合法域名
# https://your-domain.com
```

开发期：后端会自动降级走 mock（`code` 直接当 `openid`），无需配置。
