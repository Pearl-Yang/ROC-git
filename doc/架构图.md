## 核心流程：登录 → 上传 → 审核 → 分享 → 访客访问

```mermaid
sequenceDiagram
    autonumber
    participant U as 学生
    participant FE as 前端 (uni-app)
    participant BE as 后端 (Spring Boot)
    participant DB as MySQL
    participant V as 访客

    U->>FE: 微信 code / 手机号+验证码
    FE->>BE: POST /v1/user/login
    BE->>DB: 查/建 user，写 login_history
    BE-->>FE: { token, userId, ... }
    FE->>BE: POST /v1/file/upload (multipart)
    BE->>DB: insert file + file_version
    BE-->>FE: FileVO

    Note over FE,BE: 成员 B 审核
    FE->>BE: POST /v1/file/{id}/reject 或 batch-audit
    BE->>DB: update file.status + file_audit_log
    BE-->>FE: OK

    U->>FE: 点「分享」
    FE->>BE: POST /v1/share/create
    BE->>DB: insert project_share
    BE-->>FE: { shareToken, url, ... }

    V->>FE: 打开 share/visitor/{token}
    FE->>BE: GET /v1/share/visitor/{token}
    BE->>DB: 校验 share + 装配 project/stage/files
    BE-->>FE: { project, stages, files?, permissionLevel }
    V->>FE: 下载 (view_with_download)
    FE->>BE: GET /v1/file/{id}/download?shareToken=...
    BE-->>V: 文件流
```
