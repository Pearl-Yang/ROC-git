## 验收命令

### 1. 后端
```bash
cd backend
mvn verify
# 期望：Tests run: 45+, Failures: 0, Errors: 0
```

### 2. 前端 H5
```bash
cd frontend
npm ci
npm run build:h5
```

### 3. 前端 微信小程序
```bash
npm run build:mp-weixin
# 产物在 dist/build/mp-weixin
```

### 4. 启动
```bash
docker compose up -d --build
# 监控
docker compose -f docker-compose.monitor.yml up -d
# 健康检查
curl http://127.0.0.1/api/v1/health
curl http://127.0.0.1/actuator/prometheus
```

### 5. 备份
```bash
crontab -e
# 添加：
0 2 * * * /opt/rocgit/scripts/backup.sh >> /var/log/rocgit/backup.log 2>&1
```

### 6. 回滚
```bash
./scripts/rollback.sh v1.1
```
