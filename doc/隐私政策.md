# 隐私政策

> 最后更新：2026-10-14
> 依据：《中华人民共和国个人信息保护法》《数据安全法》《网络安全法》

## 一、我们收集的信息

### 1.1 账号信息
| 字段 | 用途 | 必填 | 存储位置 |
| --- | --- | --- | --- |
| 手机号 | 登录 & 短信通知 | 是 | MySQL `user.phone` |
| 微信 OpenID | 微信登录 | 否 | MySQL `user.openid` |
| 昵称/头像 | 个人主页展示 | 否 | MySQL `user.nickname / avatar` |

### 1.2 业务信息
- 您创建的项目、文件、任务、研讨记录等
- 文件版本历史、下载/预览日志（最近 30 天）

### 1.3 设备与日志
- 登录时间、IP（**30 天后自动脱敏为 `0.0.0.0`**）、User-Agent
- 错误日志（用于排障，不含敏感内容）

## 二、信息使用

我们仅在以下范围内使用您的信息：
1. 提供平台核心功能（项目管理、文件分享、消息通知）
2. 安全保障（识别异常登录、防止账号盗用）
3. 法律法规要求的协助调查

**我们不会**：
- 将您的个人信息用于推送广告
- 出售或交换您的个人信息
- 超出服务范围使用您的信息

## 三、信息共享

仅在以下情况下共享：
1. 您主动分享文件给访客
2. 法律法规要求或行政/司法机关依法查询
3. 与我们签订保密协议的服务提供商（如短信服务商、对象存储服务）

## 四、您的权利

| 权利 | 实现方式 |
| --- | --- |
| 查阅 | 我的 → 账号与安全 → 数据导出 |
| 更正 | 我的 → 个人信息 |
| 删除 | 我的 → 账号与安全 → 注销账号 |
| 撤回授权 | 注销账号或联系客服 |
| 投诉举报 | 发送邮件至 privacy@rocgit.example.com |

## 五、信息存储

- 数据库：自建 MySQL 8（主从热备）
- 文件：本地 `./data/files` 或阿里云 OSS（用户可配置）
- 备份：每日全量 + binlog，至少保留 30 天
- 加密：密码 bcrypt；JWT HS256；HTTPS 传输

## 六、Cookie 与本地存储
- 仅使用 uni-app Storage 存储登录态
- 微信小程序使用系统级 Storage；不跨平台共享

## 七、未成年人保护
本平台不面向 14 周岁以下未成年人。如发现误收集，将立即删除。

## 八、政策更新
- 重大变更将通过站内通知告知
- 继续使用即视为接受变更
