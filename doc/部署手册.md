# 部署手册（v1.2）

## 1. 一键 Docker 编排（推荐）

```bash
cd 软件设计实践
docker compose up -d --build
# 首次构建 ~60s（含 Maven 依赖）
docker compose ps
docker compose logs -f backend
```

启动后访问：
- 前端 H5：http://127.0.0.1/
- 后端：http://127.0.0.1/api/v1/health
- Knife4j：http://127.0.0.1:8080/doc.html
- MySQL：127.0.0.1:3306 (root/root, 库名 roc_git)

关闭：
```bash
docker compose down        # 保留数据卷
docker compose down -v     # 同时清掉 MySQL 数据卷
```

## 2. 外部 Tomcat（生产环境备选）

```bash
# 后端打包
cd backend
mvn clean package -DskipTests
# 生成 target/rocgit-knife4j-1.0.0.war
# 复制到 tomcat/webapps/

# 前端构建产物
cd ../frontend
npm install
npm run build:h5
# 产物在 frontend/dist/build/h5/，用 nginx 托管
```

`docker-compose.yml` 中可改用外部 Tomcat：
```yaml
backend:
  image: tomcat:9-jdk17-openjdk
  volumes:
    - ./backend/target/rocgit-knife4j-1.0.0.war:/usr/local/tomcat/webapps/ROOT.war
```

## 3. 阿里云镜像加速

`/etc/docker/daemon.json`:
```json
{
  "registry-mirrors": [
    "https://<your-accelerator>.mirror.aliyuncs.com"
  ]
}
```
然后 `systemctl restart docker`。

## 4. Maven 镜像加速

`~/.m2/settings.xml`:
```xml
<mirrors>
  <mirror>
    <id>aliyun</id>
    <name>Aliyun Maven</name>
    <url>https://maven.aliyun.com/repository/public</url>
    <mirrorOf>*</mirrorOf>
  </mirror>
</mirrors>
```

## 5. npm 镜像加速（前端依赖）

```bash
npm config set registry https://registry.npmmirror.com
```

## 6. 三端 baseURL 配置

- **H5**：开发期走 Vite proxy `/api -> 127.0.0.1:8080`；生产走 nginx 反代 `/api/* -> backend:8080/api/*`。
- **MP-WEIXIN（微信小程序）**：`frontend/.env.production` 设置 `VITE_API_BASE=https://your-domain.com/api`；要求：
  1. 域名已 ICP 备案
  2. 微信公众平台 → 开发管理 → 服务器域名 → request 合法域名：填入 `https://your-domain.com`
  3. `frontend/src/manifest.json` 关闭 `mp-weixin.setting.urlCheck`（开发期）
- **APP-PLUS（APK）**：默认 `http://10.0.2.2:18080/api`（Android 模拟器映射宿主）；真机调试可填局域网 IP。
- **iOS**：`Info.plist` 添加 `NSAppTransportSecurity.NSAllowsArbitraryLoads=true`（仅开发）。

## 7. 环境变量

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 | root |
| `MYSQL_DATABASE` | 初始库名 | roc_git |
| `BACKEND_PORT` | 后端暴露端口 | 8080 |
| `FRONTEND_PORT` | 前端暴露端口 | 80 |
| `TZ` | 时区 | Asia/Shanghai |
| `JAVA_OPTS` | JVM 参数 | -Xms256m -Xmx512m |
| `SMS_PROVIDER` | 短信通道（log/tencent） | log |
| `TENCENT_SMS_*` | 腾讯云短信凭证 | （空） |

## 8. 数据卷

| 容器 | 路径 | 主机路径 |
| --- | --- | --- |
| mysql | /var/lib/mysql | ./data/mysql |
| backend | /data/files | ./data/files |
| backend | /app/logs | ./data/logs |

## 9. 备份

```bash
# 备份 MySQL
docker exec roc-mysql mysqldump -uroot -proot roc_git > backup_$(date +%Y%m%d).sql

# 备份上传文件
tar czf files_$(date +%Y%m%d).tgz ./data/files

# 恢复
docker exec -i roc-mysql mysql -uroot -proot roc_git < backup_xxx.sql
```

## 10. 升级 / 回滚

```bash
git pull
docker compose down
docker compose up -d --build

# 回滚到 v1.1
git checkout v1.1
docker compose down
docker compose up -d --build
```
